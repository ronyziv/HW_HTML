סעיף א' - הסבירו בקצרה מהי מערכת מידע ומה תפקידה בארגון

מערכת מידע היא אוסף מרכיבים שקשורים בניהם ואוספים, מעבדים ומספקים מידע על מנת לתמוך בקבלת החלטות, תיאום ושליטה בארגון

מתפקידה המרכזי של מערכת המידע היא לאפשר לארגון לפעול בצורה מדוייקת ואפקטיבית. היא מייעלת תהליכים עסקיים בארגונים ומוסדות שונים, זאת באמצעות לקיחת נתונים יבשים, הפיכתם למידע והפקת מסקנות למשתמש

על פי המסקנות הללו מתאפשר למשתמש קבל החלטות מושכלות

סעיף ג' - תארו בקצרה מהו מחזור החיים של מערכת מידע? מדוע חשוב לנהל את תהליך הפיתוח בצורה מסודרת?

SDLC הוא בעצם כל השלבים לפיתוח מערכת מידע, מהרעיון, ליצירת המערכת ועד לתחזוקה שלה.

המטרה - שהמערכת תהיה יעילה, תענה על המטרות והצרכים שלשמה היא נוצרה ותנהל את התהליכים העסקיים בצורה אפקטיבית

מחזור החיים של מערכת המידע יתחיל בתכנון קפדני, באמצעות זיהוי הצרכים, לאחר מכן יתבצע ניתוח דרישות בכי להבין באילו תהליכים המערכת תצטרך לעסוק, ואז פיתוח המערכת, בדיקדות המערכת, והטמעה שלה, ושיור תחזוקה שוטפת שלה.

חשוב שהתהליך יהיה לפי השלבים ומסודר בכדי שהמפתחים ישארו ממוקדים ויפעלו בהתאם לתכנון ובכך ימנעו אי סדר ואי הבנות בין המפתחים, סטייה מהמטרות ומהצרכים שיש לענות עליהם.

סעיף ד'- הסבירו את ההבדל בין HTML ל-CSS? ומה תפקיד כל אחד מהם בבניית עמוד אינטרנט?

HTML זוהי שפת תגיות ואילו CSS זוהי שפת עיצוב

CSS מיועדת לעצב דפי HTML ומגדירה איך יראו האלמנטים בעמוד אינטרנט

ההבדל בניהן הוא בונה את המבנה של הדף (כמו טקסטים, כפתורים, כותרות) ואילו CSS אחראית על הגדרת העיצוב - הגופנים, הגודל הצבעים וכדומה.
